KeyDBX 是 KeePass 相容的 iOS 密碼管理 App。開發者沒有伺服器，也看不到你的資料。

瀏覽功能支援與問題回報

  • 讀寫 KDBX 4.0 與 4.1
  • 開發者沒有伺服器
  • 沒有分析、廣告與追蹤
  • 介面語言：正體中文與英文

功能

桌面版的資料庫，在 iPhone 上照常使用

  • KeePass 資料庫

    讀寫 KDBX 4.0 與 4.1，支援主密碼與金鑰檔。存檔只改你修改的部分，KeePass 與 KeePassXC 可以繼續開啟同一個檔案。

  • 自動填寫

    在 Safari 與其他 App 填入帳號、密碼與兩步驟驗證碼。建立帳號或更改密碼時，可以把新密碼存進 KeyDBX（iOS 26.2 或以上）。

  • Passkey

    為網站建立與使用 passkey。儲存格式與 KeePassXC 2.7.12 以上相容。

  • 兩步驟驗證碼

    顯示 TOTP 驗證碼，包含 Steam 驗證碼。以相機或照片掃描 QR code 設定，或開啟 otpauth:// 連結。

  • Face ID

    以 Face ID 解鎖 App 與自動填寫，不必每次輸入主密碼。

  • Dropbox 同步

    直接開啟與存回 Dropbox 上的資料庫，不需要安裝 Dropbox App。兩邊都修改時，Dropbox 另存一份副本，不覆蓋任何版本。

  • 「檔案」與 iCloud Drive

    開啟「檔案」App 中的資料庫，包含 iCloud Drive 與其他雲端空間。

  • 離線可用

    沒有網路時仍能解鎖與編輯 Dropbox 上的資料庫，連線後再上傳。

  • 隱私保護

    自動鎖定、在 App 切換器隱藏內容、螢幕錄影時隱藏密碼。複製的密碼只留在這台裝置，60 秒後清除。

互通性

與桌面版共用同一個檔案

存檔只改你修改的部分，KeePass 與 KeePassXC 可以繼續開啟同一個檔案。Passkey 的儲存格式與 KeePassXC 2.7.12 以上相容。

兩邊都修改時，Dropbox 另存一份副本，不覆蓋任何版本。

更多功能

  • 密碼產生器與密碼強度提示。
  • 項目的歷史版本：查看、比較與還原。
  • 以 Credential Exchange 與其他密碼管理 App 互相匯入與匯出。
  • 介面語言：正體中文與英文。

系統需求

iOS 26 或以上。儲存新密碼需要 iOS 26.2 或以上。

不支援

  • KDBX 3.1 與 KeePass 1.x 的資料庫。
  • YubiKey 與 HOTP。
  • Dropbox 以外的雲端服務直接連線。其他雲端空間請經「檔案」App 開啟。

KeyDBX 不收集你的資料

沒有分析、廣告、追蹤或第三方 SDK。App 本身只在你使用 Dropbox 時連線網路，而且只連到 Dropbox。

閱讀隱私政策

KeePass、KeePassXC、Dropbox、Apple、iPhone、iCloud 與 Face ID 是各自擁有者的商標。KeyDBX 與這些擁有者沒有關聯。
